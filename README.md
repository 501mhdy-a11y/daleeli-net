# دليلي نت — MVP Starter

مشروع بداية لتطبيق متجر كروت إنترنت متعدد الشبكات.

## المحتويات
- `flutter_app/`: واجهة Flutter عربية RTL قابلة للتشغيل والتطوير.
- `backend/`: ملفات بداية لخادم Laravel (مسارات API، نماذج، وترحيل قاعدة بيانات أولي).

## حالة النسخة
هذه نسخة MVP تجريبية ببيانات محلية. زر الشراء ينفذ محاكاة محلية ولا يستقبل أموالاً ولا يصدر كرتاً حقيقياً.
لا يوجد ربط فعلي مع MikroTik أو Smart Creator أو بوابة دفع حتى الآن.

## تشغيل واجهة Flutter
1. ثبّت Flutter SDK وAndroid Studio.
2. افتح مجلد `flutter_app`.
3. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```

## تجهيز Laravel
أنشئ مشروع Laravel حديثاً ثم انسخ مجلدات `app` و`routes` و`database` إلى مشروع Laravel.
اضبط اتصال PostgreSQL في `.env` ثم نفّذ:
```bash
php artisan migrate
php artisan serve
```

## قبل الإطلاق
- إضافة تسجيل دخول آمن وصلاحيات الأدوار.
- ربط بوابة دفع حقيقية والتحقق من webhooks.
- تنفيذ حجز ذري للكرت لمنع البيع المكرر.
- تشفير أسرار الراوتر وعدم تخزينها كنص مكشوف.
- بناء موصل MikroTik مع VPN/وكيل اتصال آمن واختباره على راوتر فعلي.
- التحقق من وجود API موثق لـ Smart Creator قبل بناء التكامل.
- إضافة اختبارات آلية وسجل تدقيق ومراقبة أخطاء.
